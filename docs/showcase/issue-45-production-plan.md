## 叙事与取材

原分镜围绕一次位置访问对照展开：准备 APK 和两份独立来源，查看候选与原句，读实际阶段，进入结果，再回到同一版本的代码和政策。用户随后要求 Gemini 完全重写且在文案上优先；实际叙述采用 Gemini 全稿及其事实修订，见 [copy-provenance.json](../../showcase/privacytrace/copy-provenance.json)，本表只保留制作时的结构草稿。主代理没有按自己的文风再改写；仅做数据映射和按词换行。主体使用新构造的二进制位置 APK、两份独立人工政策和一个被拒的私网网址，不复用冻结 C02 的输入。实际操作经过生产网页与 HTTP 接口、真实 DeepSeek 请求、普通 APK 上传 lane、受限 Docker 和持久化报告。政策 HTTP 和 DNS 目标是明确标注的本地取材夹具，不能称作第三方公开网页的本轮抓取验收。

完整网页流程与冻结评测是两组证据。网页中新建候选或用户修正不会替换原评测人工输入，也不能拿新报告改写历史比较数。主案例的两条位置结果均为 INSUFFICIENT_EVIDENCE；C02／C03／C05／C06 与六场景数字仅在明确标识的历史受控摘要段落出现。

产品截图是上述实际操作的录制回放，段内持续标注“构造输入／人工政策／实录回放”，不冒充影片播放时现场扫描。API 字节码和人工政策原句来自同一个新报告；#44 原来的固定“纸舟地图”示例不用于主路径。原始截图保持不变，镜头只裁切或放大；大字号旁注明确是同一记录的摘录或字段，不伪造产品控件。

## 视觉与阅读

借鉴 Pioneer Cinematic v8 的实际片头、连续线条、局部聚焦和确定性时间轴；不复制其角色、画面、文案或配乐。已检查实际成片代表帧和 `film.mjs`／`render.cjs` 机制，原片是 60 秒，本片独立编排 180 秒。

- 色彩：电影画布 #101921，暖白字幕 #F7F3E9，线条 #7BAE9C，弱提示 #B7B5AA。产品截图保留当前 Pioneer 规范的 #F6F5F1 画布、#FDFCFA 面板和 #333C50 按钮，不重新换肤。
- 字体：标题使用项目已有 Noto Serif SC；字幕与操作说明使用 Noto Sans SC。随包保留各自 OFL 文件，不使用远程字体。正文与字幕左对齐。
- 构图：产品主画面占上方主体，字幕留在下方固定阅读区。外侧保留来源标识和任务身份，不遮住产品自身的未知、失败、未检查状态。
- 识别元素：一条“证据线”从代码位置延续到政策原句；其移动由时间轴计算。线条只组织阅读，不暗示运行时数据传输或调用可达性。
- 镜头：切入页面时可轻微透视推近；读原句、代码、状态和统计时恢复正面，停留至少 4 秒。小字号内容改用原生浏览器高分辨率局部捕获，不靠放大低分辨率图补字。
- 可读区：1920×1080 的字幕左右留至少 96px，主字幕 42px，辅助字幕 28px；主说明控制为一至两行。实际验证字形、换行、停留时间与画面对应；原句摘录按语义断行，避免孤立标点。

## 离线播放器与导出方案

使用同一个纯时间状态函数驱动 HTML 和逐帧导出；所有位置、透明度、焦点、高亮及字幕都由传入秒数决定。直接 seek 与顺序播放到同一时间必须一致，不能依赖之前发生的点击、计时器或随机动画。播放器提供播放／暂停、重播、可拖动时间轴、全屏和键盘操作；进入时默认暂停，控制不会盖住影片字幕。

仅加载包内素材。prepare 将 JSON 生成本地经典脚本并带上字体及许可，HTML 可从 file:// 打开。实际 Chromium 在导航前设置 offline=true，重新加载所有本地资源并执行控制；没有 service worker 或预先缓存的远程资源。本地静态服务仅为可选的回环预览入口。

Chromium 按 1920×1080、deviceScaleFactor=1 捕获 5400 帧。渲染前等待字体与图像解码；保存素材集合哈希，变化后使用新帧目录，禁止混用旧帧。FFmpeg 编码 H.264、yuv420p、30fps，并将本地 48kHz 配乐编码为 AAC。字幕来自页面像素并烧录入画面。缓存和依赖不进源码包。

配乐另行原创生成，记录生成源码、确定性参数和音频哈希，不使用 Pioneer 音轨或未核对许可的录音。无旁白。成片分别验证音轨覆盖、响度、峰值、首尾淡入淡出、实际浏览器音频播放；不据自动测量声称用户认可听感。
