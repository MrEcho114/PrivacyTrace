- 第一版受控输入没有 launcher，原生选择器不可见；新建含 launcher 的 v2 后才执行，旧尝试未计通过。

  25/23 项失败；修正私有环境后同一元数据扫描恢复。这些历史失败保留，不写回旧 SHA。

  queued 快照实际为 DELIVERED，才进行后续投递后中断，未按文件名虚报时点。
- 一次外部环境中断使 Desktop/模拟器停止，恢复本票资源后继续；这不是受控独立 VM 重启证明。
- 早期轮次未单独保存完整控制面镜像 ID；组合候选的角色身份单独记录，未用新身份补写旧轮次。

  cgroup v2 探针文件缺失。没有修改测试、断言、隔离或 skip。组合候选后一次权威尝试在镜像构建
  的锁定依赖下载阶段失败，未执行测试；也单独保留。
- 两修复的独立运行时套件 **238 passed / 0 skipped**；测试移动到既有 CI 模块后，worker 与
  deadline 守卫另跑 **22 passed**。API 后续权威命令单独实跑：E2E65、Web111，Ruff、研究包、
