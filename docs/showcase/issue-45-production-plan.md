## 叙事与取材

用户最新要求参考 Pioneer 的实际镜头并将片长缩为两分钟。当前采用 Codex 原创 18 镜：分层安装包、空间界面长廊、代码／政策双页对照和报告收拢。文案延续 humanizer-zh、writing-clearly-and-concisely 和 ux-writing 的具体动作与发现；镜头设计使用 frontend-design。见 [现行两分钟镜头与文字稿](issue-45-cinematic-120.md)、[历史导演稿](gemini4-director-review.md)和[归属记录](../../showcase/privacytrace/copy-provenance.json)。主体使用新构造的二进制位置 APK、两份独立人工政策和一个被拒的私网网址，不复用冻结 C02 的输入。实际操作经过生产网页与 HTTP 接口、真实 DeepSeek 请求、普通 APK 上传 lane、受限 Docker 和持久化报告。政策 HTTP 和 DNS 是本地取材夹具。

完整网页流程与冻结评测是两组证据。网页中新建候选或用户修正不会替换原评测人工输入，也不能拿新报告改写历史比较数。主案例的两条位置结果均为 INSUFFICIENT_EVIDENCE；C02／C03／C05／C06 与六场景数字仅在明确标识的历史受控摘要段落出现。

产品截图是上述实际操作的录制回放，段内持续标注“构造输入／人工政策／实录回放”，不冒充影片播放时现场扫描。API 字节码和人工政策原句来自同一个新报告；#44 原来的固定“纸舟地图”示例不用于主路径。原始截图保持不变，镜头只裁切或放大；大字号旁注明确是同一记录的摘录或字段，不伪造产品控件。

## 视觉与阅读

借鉴 Pioneer Cinematic v8 的实际片头、空间面板、局部聚焦和确定性时间轴；不复制其角色、画面、文案或配乐。已检查实际成片代表帧和时间轴机制，原片是 60 秒，本片独立编排 120 秒。

- 色彩：采用 Gemini4 的 #080909 深黑画布，中心微光 #131619，暖白 #EEE8D8／#D0C9B9，橙／金／灰绿细线用于局部标记；历史案例卡为 #111316。没有浅绿整屏背景。原始产品截图保留其捕获时的浅色界面，不重新涂改。
- 字体：采用 Gemini4 的 Noto Sans SC 绘制方案；包内保留已有 Noto 字体及各自 OFL，不加载远程字体。正文与字幕左对齐，长节点标签按可用宽度适配。
- 构图：产品主画面占上方主体，字幕留在下方固定阅读区。外侧保留来源标识和任务身份，不遮住产品自身的未知、失败、未检查状态。
- 识别元素：一条“证据线”从代码位置延续到政策原句；其移动由时间轴计算。线条只组织阅读，不暗示运行时数据传输或调用可达性。
- 镜头：切入页面时透视推近并对焦，关键原句、编辑、代码、政策来源和统计恢复正面后稳定超过 4 秒；完成状态与历史案例概览较短，最短阅读段 2.45 秒，可暂停查看。原始截图局部裁切放大，未重绘产品文字。
- 可读区：1920×1080 字幕左右保留 90px，按标题、正文和批注层级排字。每镜独立绘制当前内容，批注在本镜相机接近停稳时淡入，不再叠加上一镜文字。实际检查字形、换行、停留时间与画面对应。
- 文案：片头／片尾只显示一组主副标题，去掉底部重复字幕；批注直接进入内容，GKD 状态译为“部分提取／尚未复核／尚未检查”。原 PNG 和历史数据不变。

## 离线播放器与导出方案

使用同一个纯时间状态函数驱动 HTML 和逐帧导出；所有位置、透明度、焦点、高亮及字幕都由传入秒数决定。直接 seek 与顺序播放到同一时间必须一致，不能依赖之前发生的点击、计时器或随机动画。播放器提供播放／暂停、重播、可拖动时间轴、全屏和键盘操作；进入时默认暂停，控制不会盖住影片字幕。

仅加载包内素材。prepare 将 JSON 生成本地经典脚本并带上字体及许可，HTML 可从 file:// 打开。实际 Chromium 在导航前设置 offline=true，重新加载所有本地资源并执行控制；没有 service worker 或预先缓存的远程资源。本地静态服务仅为可选的回环预览入口。

Chromium 按 1920×1080、deviceScaleFactor=1 捕获 3600 帧。渲染前等待字体与图像解码；保存素材集合哈希，变化后使用新帧目录，禁止混用旧帧。FFmpeg 编码 H.264、yuv420p、30fps，并将本地 48kHz 配乐编码为 AAC。字幕来自页面像素并烧录入画面。缓存和依赖不进源码包。

配乐另行原创生成，记录生成源码、确定性参数和音频哈希，不使用 Pioneer 音轨或未核对许可的录音。无旁白。成片分别验证音轨覆盖、响度、峰值、首尾淡入淡出、实际浏览器音频播放；不据自动测量声称用户认可听感。
