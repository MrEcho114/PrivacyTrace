# 已采纳 #167：功能命名与边界文案合同

2026-10-22 用户明确要求“采纳并融入 issue165”。来源：[Issue #167](https://github.com/MrEcho114/PrivacyTrace/issues/167)。本合同属于 [#165](https://github.com/MrEcho114/PrivacyTrace/issues/165)，沿用同一设计基座/PR #166；#167 保留来源，不成为另一条并行执行入口。

## 采用的决定

1. 四步名称统一为：**APK 与政策材料 / 核对政策声明 / 扫描与对照进度 / 对照报告**。
2. 顶栏副标题：**隐私权限使用与隐私声明对照**。报告唯一一级标题：**APP 隐私收集越权报告**。
3. 对照节：**数据类型与政策声明对照**。完整产品表格列名使用“数据类型”“证据”；同步单元格 data-label 和窄屏验收选择器。
4. 阶段名只定义一次：等待处理、核对材料、隔离扫描 APK、装载政策原文、规则对照、生成报告、报告已生成、分析失败、已取消。展示页没有真实阶段状态机，本轮不伪造进度面板。
5. 政策状态行由一个函数生成。默认展示“来源未复核 · 正文完整度未知 · 附件未检查”，实际值逐项映射；正文完整不意味着来源已复核，缺失值仍为未知。提取状态单独保留，不能随去重删掉事实。
6. 每个边界事实放在读者需要的位置，不在页头、面板、页脚反复警告。报告首屏说明对照的两端与静态边界；对照节说明结论范围。
7. 示例态只保留一个全局标记：**示例体验 · 固定材料**。证据里的“人工构造的静态片段”等材料身份仍保留。
8. 报告和本机存档入口每次只显示一个 h1、一组品牌栏。进度页标题描述阶段，不用“纸舟地图”等示例应用名冒充阶段标题。
9. 使用既有 copy 模块集中公共命名/长句，避免各组件另存步骤名。旧 homeTitle、homeDescription、scopeHelp、demoTitle、candidateDescription、modelHelp、sourceRecovered、unsavedText、sampleOnly、realInputHelp 十键待完整业务迁移后确认未引用再删除，不能先删破坏现存页面。
10. 不修改作业状态机、API/生成契约、字段名、结论枚举或政策核算规则。错误/空状态的全面改写、ADR 编号冲突、合并/发布/部署均不在本合同内。

“隐私权限使用”和“越权”按用户采纳的展示命名执行。它们不是引擎新增能力，不将静态线索升级为实际采集、违规、安全或法律判断。沿用 GLOSSARY 的事实边界；首屏范围说明保留。
