## 制作方式

- 单文件 HTML，所有画面由 `window.__seek(t)` 纯函数驱动；无 CSS transition/animation、无 `Math.random()`；同一时间点重复渲染一致。
- 使用 EAC `render-template` 逐帧渲染（Playwright + Edge headless），v0.2 job `52611270-940b-468a-adb7-b6211ce497f1`；音频为项目原有原创器乐 `soundtrack.m4a`（96 BPM，48 小节 = 120.000 s）。
- 主切点落在 96 BPM 整小节：9.375 / 21.875 / 40.625 / 65.0 / 90.0 / 108.75 s。
- 画面素材为真实产品截图（`assets/`）与排版图形；未使用 AI 生成图像。片尾注明本片由 AI 辅助分镜与排版。
- 采集与重采脚本：`showcase/materials-20261023-v02/capture-stills.cjs`、`capture-mobile-report.cjs`；批次说明见同目录 `README.md`。
- PPT 用 python-pptx 生成，10 页、可编辑文本与形状，含逐页演讲备注；截图与影片同源（本批次未改 PPT）。
