# Issue #145 · 交互状态、键盘焦点与无障碍交接

来源任务：[子票 #145](https://github.com/MrEcho114/PrivacyTrace/issues/145)，父规格 [#141](https://github.com/MrEcho114/PrivacyTrace/issues/141)。实现基线 `main` `b5b7237`（含 #142/PR #150 的 Pioneer token 与 Reka `UiDialog`）。视觉依据沿用父票与 [A 票交接](issue142-theme-and-primitives.md) 已核实的 [Pioneer 当前设计 824:1279](https://www.figma.com/design/EQis9ep9ZQsEenrUVXwlFU/Pioneer?node-id=824-1279) 与 [规范页 824:1276](https://www.figma.com/design/EQis9ep9ZQsEenrUVXwlFU/Pioneer?node-id=824-1276)。

本票不新增页面、业务、API、生成契约、主题、动效或第二套组件库；只收敛已存在状态的文字/焦点/可访问名称/aria，并修实际可达的交互缺口。动画机制与减少动效参数归 E 票 #146，软键盘/安全区/触控归 C 票 #144，宽屏视觉层级归 B 票 #143。

## 关键实现

- **原地刷新**：`App.vue` 把“替换来源”和“刷新当前来源”分开。来源切换才清空旧报告；轮询和手动刷新保留报告、选中证据与阅读位置，只更新任务/报告数据。真实状态变化通过一个 `role=status` 的隐藏文本播报一次；轮询本身不播报。
- **焦点返回**：运行中任务完成、取消、重试、删除后，如果原按钮消失导致焦点落到 `body`，焦点回到任务状态卡或结果消息；证据收起回到触发行；删除确认取消后回到“删除任务”；设置关闭后回到“项目设置”。
- **删除确认**：继续使用既有两步内联确认，不引入第二个模态；确认区为命名 `role=group`，由不可恢复说明描述，打开时聚焦“确认删除”，Esc 关闭，Tab 在确认/取消之间自然移动。危险操作仍需第二次显式确认。
- **live region 纪律**：`role=status`/`role=alert` 只承载文字，不嵌按钮；不再给会阻塞 `aria-hidden` 的页面级 live region 手写 `aria-live`（Reka + `aria-hidden` 库会保留带 `aria-live` 的节点，导致模态打开时应用主体未被隐藏）。必要的一次性状态变化由 `role=status` 的隐式 polite 语义承载。
- **手机后台轮询**：原生桥不可中止，使用 epoch 失效规则；任何前台操作（取消、重试、换实例、删除、准备、保存）都会推进 epoch，迟到的轮询结果只丢弃，不覆盖新任务状态或用户刚产生的错误。
- **停止本次请求**：准备、导入回填、候选保存、开始分析、取消、重试都改为使用当前 `perform` 的 `AbortSignal`；停止按钮只对真正可中止的请求显示/生效，不再出现“已取消但请求仍在跑”的假取消。
- **错误贴近操作**：导入/候选页的页面级错误移到主操作附近；字段错误继续由 `UiField` 关联。重试/保存失败不写入短暂 Toast。
- **复用**：Reka `UiDialog`、`UiButton/UiField/StatusTag/UiIcon`、原生 `select/details/summary` 全部复用；没有新增库、没有全站换库、没有新增业务状态机。

## 验证口径

- `apps/web` 单测读取 `App.vue` 暴露的 `reload`，本票保留该入口作为“替换来源”的显式语义；新行为另有 `loadData(mode)` 内部参数。
- 浏览器验证使用确定性响应夹具：不执行真实 APK、Docker、模型或外部网页；真实读屏、真机与辅助技术不在本机自动化范围，按 NOT_RUN 记录。
- 对比度用实际 token 计算，焦点环用键盘 `Tab` 后的计算样式测量；组件库自称无障碍不替代页面验证。

## 已知边界

- 证据面板的平滑滚动仍受 E 票 #146 的减少动效统一管理；本票未改动画参数。
- 手机软键盘/安全区、真实触控与横屏归 C 票 #144；本票只处理共享状态/焦点语义。
- 设置中的“清除示例草稿”保留原有立即执行与说明，不把示例草稿提升为任务删除级别。
- 真实 NVDA/VoiceOver、真实 Android 设备、真实模型与 Docker 未在本票运行；浏览器 AX tree 只证明 Chromium 语义，不替代人工读屏体验。
