## 服务接缝与限额

`/api/v1/web/` 提供 settings、drafts、流式 APK、每来源 fetch／extract、candidate save 和 start。写请求要求本机 Host、Origin 和 `X-PrivacyTrace-Local: 1`；输入错误仅返回固定错误码，避免 Pydantic 回显正文和密钥。后端只绑定回环，单个 Web intake 进程持有本机 store 所有权锁。

- APK 上限沿扫描器为 150 MiB；12 个本机材料目录、每目录 256 个输入版本／128 MiB 历史、10 次作业尝试；最多 2 个扫描线程、4 个未完成请求。超额拒绝，不自动删除用户材料。
- 网页仅 HTTP(S) 标准 80／443 端口，逐次校验 DNS 和跳转并连接已核验 IP，保留 HTTPS 主机验证；不访问私网、回环、链路本地、保留／组播地址或本机路径。不使用网页抓取代理设置。15 秒总预算、3 次跳转、2 MiB 响应、200000 个正文字符；不自动解析脚本、PDF 或附件。
- 本机代理返回全部 `198.18.0.0/15` 的域名解析时，通过固定 AliDNS HTTPS JSON 端点查询 A 记录，再仅接受公网地址并固定连接。直接 IP、混合公私地址和其他私网解析仍拒绝；不改全局 DNS／代理。系统 DNS 和公共 DNS 都在短生命周期子进程内受超时限制；连接、TLS 握手和响应读取共享总时限。
- 模型最多处理 4 个 4000 字符块、4 个请求、120 秒、每来源 100 条候选。未处理块、异常输出和被拒原句保留执行状态，不能声称全文抽取完成。

网页正文和手动材料一律 `PARTIAL / UNREVIEWED / NOT_CHECKED`；模型返回和候选保存不提升这些事实。适用包名、versionCode、地区和产品范围需用户明确提供，空值保持未知。普通上传不接收受控事实、不按文件名或网址推断来源与适用范围。后端输入与版本保留在被忽略的本机 `data/` 存储，供刷新与重试；扫描器自己的容器副本仍按原配额和退出清理约定删除。

来源网址在编辑材料时保留用户输入；展示的来源元数据、报告证据和抓取收据移除用户名／密码、片段并遮盖查询值。收据保存原网址哈希以绑定输入，不公开可能携带签名的查询值。
