# Gemini 文案事实简报模板

用于交给 Gemini 前核实内容；具体任务的已填简报及输出留在忽略的临时目录。此模板不构成发送授权。

## 来源与范围

- 本轮目标、页面及采用的设计来源。
- 用户已授权的模型目的地、具体发送材料和同范围修订边界。
- 风格：自然、直接中文；说明具体操作、结果与限制，使用项目术语。

## 功能事实

| 场景 | 实际行为 | 核实来源 | 文案键名 |
| --- | --- | --- | --- |
| 真实接口与连接 | 哪些接口已可用，哪些仅保留页面入口 | 代码或接口响应 | 待填 |
| 示例 | 数据是否固定，编辑是否触发重新计算 | 代码及浏览器 | 待填 |
| 输入 | 上传与抓取是否执行，支持格式和限制 | 代码及契约 | 待填 |
| 失败、取消与恢复 | 状态转换、输入保留、重试范围 | 代码及浏览器 | 待填 |
| 草稿与备注 | 持久化字段、自由文本及刷新行为 | 代码及浏览器 | 待填 |
| 政策与静态证据 | 事实、声明、推断及 UNKNOWN 的含义 | 项目边界和契约 | 待填 |

## 交付与纠错

列出需要输出的键及格式。对最新响应逐项核对上表；发现错误时反馈具体错误、正确事实及核实来源，在已授权的纠错范围内交给 Gemini 修订。保留每次输入、原始响应和最终采用版本，不复用旧会话残留的 structured_output。
