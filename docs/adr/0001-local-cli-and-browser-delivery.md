# 本期采用本地 CLI 分析与浏览器报告展示

> **注记（2026-10-22，ADR-0004）**：本决策的「浏览器报告展示」作为展示客户端的部分，已被 [ADR-0004（`0004-client-is-android-app.md`）](0004-client-is-android-app.md) 部分取代：客户端在本项目中仅指 Android App；浏览器产物不再充当展示客户端：用户操作面收窄（工程调试、内部走查），工程验收介质与离线回放载体保留。本决策中「本地 CLI 执行真实扫描」的部分继续有效；标题与正文保持原样，本注记只新增、不改写。

用户选择可验证的竞赛作品为下一阶段目标，保留 2026-10-17 代码冻结，并接受本地 CLI 执行真实扫描、浏览器查看报告。本期不新增浏览器 APK 上传和多人公网服务：这些能力会引入额外的数据接收、身份授权与隔离边界，挤占受控评测和离线交付的时间；保留现有本地链路能将有限资源集中在证据可追溯及谨慎降级。

实时执行与离线回放必须明确区分，不能把旧报告展示冒充现场分析。这是本期范围选择，不宣称公网服务永远不需要，也不代表交付包已经完成。
