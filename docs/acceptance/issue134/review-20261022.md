## 修订及回归

| Review 项 | 修订 | 验证 |
| --- | --- | --- |
| 私有响应属性链可能抛出 AttributeError | `_set_read_timeout` 使用受保护的属性读取；无法设置读超时时返回 RuntimeUnavailable，不继续无界读取 | 缺失响应包装与 setter 抛 AttributeError 均在修复前失败、修复后通过 |
| remote.timeout 缺少前置条件 | RunnerClient 在任何材料/HTTP I/O 前校验传输上限为正有限数，拒绝 None、bool、字符串、无穷、NaN 等配置 | 检查与扫描入口均要求明确配置错误，禁止触达 I/O |
| 墙钟断言对 CI 抖动敏感 | 实际 mTLS 总耗时上界由0.58s改为0.7s；另用可控时钟断言头部后及后续读取剩余预算为0.75s、0.5s | 预算不能按头部或每次读取重新发放；真实 mTLS 的0.45s操作仍必须失败 |
| 完整故障验收边界 | 原证据包保持逐字节不变 | F01/F02/F03/F04/F07完整通过仍0/5，#134/#128保持开放 |

复测还发现可重复的浮点取整边界：绝对截止点相减产生
`0.1500000000014552`，大于已配置的0.15s上限，导致原传输层拒绝。
`_remaining` 现在再次封顶到已验证上限；既有真实 mTLS 测试固定可产生该取整的
Runner 时钟，跨平台守住此边界。没有放宽传输上限、响应大小、TLS 或容器隔离。
