### 承诺书流程

1. **必须是系统生成版**：承诺书由报名系统按填报信息自动生成并下载；官方说明的开放时点为提交作品之后，未提交前入口不开放。以系统内下载的版本为准，通用模板无效。
2. **盖章部门三选一**：教务处、二级学院（学院/系部）、校级学科竞赛管理部门任一即可；跨校组队统一加盖队长所在院校对应部门公章。
3. **信息变更即失效**：盖章后若修改师生姓名、学校名称、作品名称或作品分类，须重新下载新版承诺书并重新盖章。
4. **单独上传**：承诺书不进压缩包，与打包文件是两条独立路径。

**10 张运行截图已于 2026-10-20 21:00 补齐**，存于 `05_补充成果材料/截图/`，附逐张说明。截图取自"体验示例"路径（前端内置固定材料，报告显示 3 行），由真实运行界面的自动化流程生成，未做后期修改；该路径不需要后端服务，此前记录的"需后端运行环境"不成立。
