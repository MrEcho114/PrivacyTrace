# 第一开发里程碑：一个真实样本

当前状态：S1 已于 2026-10-09 按用户决定接受技术核验；撤销双人逐条 comment/签字门槛。见 [接受决定](stages/s1-acceptance-20261009.md) 与 [真实样本技术记录](stages/s1-pr29-real-sample-verification-20261009.md)。PR29 仍待独立合并决定，main 不伪称已更新。

| 项目 | 需要的产物 | 验收 |
|---|---|---|
| M1 | 官方渠道真实 APK，包名、版本、SHA-256、获取时间和来源 | 能复核同一版本，APK 保持本机 |
| M2 | Permission + Sensitive API Evidence | 每条定位文件、Class、Method；区分权限能力和 API 访问 |
| M3 | 至少一份真实政策 | 来源、版本/适用版本、采集时间、快照哈希完整 |
| M4 | 结构化 PolicyClaim | 每条回到政策原句；事实、声明、推断分离 |
| M5 | Consistency Engine | 按规则版本产生状态及 Evidence IDs |
| M6 | 3–5 条可解释结果 | 证据可溯源，静态措辞准确，未知如实保留 |
| M7 | 点击结果查看代码与政策 | 2–3 次点击到依据，缺失声明可查看完整政策 |

下一轮进入 S2 受控场景和基准评测。代理负责自动验证、完整 diff 与 PR 记录，不要求用户填写人工核验表。

保存样本登记、政策快照、规则版本、实际测试结果、脱敏截图与真实提交；保留历史复核记录但不补造新复核。取消团队门槛不改变政策 UNREVIEWED 或缺证据结果。
