# 客户端是 Android App：浏览器三分与 App 能力冻结

状态：已定稿，待 PR 合并生效（2026-10-22）。本 ADR 部分取代 [ADR-0001](0001-local-cli-and-browser-delivery.md)《本期采用本地 CLI 分析与浏览器报告展示》：取代其中「浏览器报告展示」充当面向用户的展示客户端的部分（浏览器仍作工程展示与离线回放保留）；其「本地 CLI 执行真实扫描」与「实时执行和离线回放必须区分」继续有效。

本 ADR 是口径的决策源，不改变代码、构建、部署与验收链路。它解决的不是功能问题，而是词过载：仓库里「浏览器」同时承担用户操作面、工程验收介质、离线回放载体三种身份，此前没有任何一处把它们拆开。

## 1. 客户端

客户端 = 用户可操作的产品界面。本项目仅指 **Android App**：Tauri 2 壳（`apps/mobile/`）及其加载的移动界面。桌面 Web 工作台不是客户端。

用户第一次接触产品的正规路径是 Android App；零安装路径是离线回放包。二者之外不再宣称第三个入口。

## 2. 浏览器：三种身份、两个验收名

浏览器产物在本项目承担三种不同身份，必须分开称呼：

| 身份 | 处理 | 允许用途 | 不得用于 |
| --- | --- | --- | --- |
| 用户操作面 | 收窄 | 工程调试、内部走查 | 不得称为客户端或产品入口 |
| 工程验收介质 | 保留（部署拓扑必需件） | 浏览器回归、工程截图证据（非赛事材料）、界面契约证明 | 不得称为客户端；不得替代客户端实机验收 |
| 离线回放载体 | 保留（部署拓扑必需件） | 只读回放、断网展示、考核兜底 | 不得称为客户端；不得冒充现场分析 |

浏览器里的固定材料「示例体验」改称**工程演示夹具**：它不是客户端，也不表示正在分析所选 APK。该改称只在文档与口径中生效，不改界面文案或代码。

两个验收名不得互换或互相替代：

- **界面契约回归**：生产 Vue 界面 + 受控原生桥替身，证明界面契约、交互状态与无障碍下限；现有入口为 `npm run acceptance:mobile` 等，其输出不得记为客户端实机验收。
- **客户端实机验收**：真实安装包在设备上的验收矩阵，证明安装、启动、主流程与清理行为。

浏览器加模拟原生桥的走查不能记为真机通过。

## 3. App 能力集：按现状冻结

现状能力按用户路径固定为：选包 → 确认上传 → 政策准备（自动/辅助/个人模型）→ 候选 → 启动分析 → 进度 → 报告 → 删除远端材料。

以下浏览器独有能力**有意不补**进 App，不是缺陷，也不排期：复核备注、跨任务浏览与任意任务删除、服务端模型 Key 设置、示例旅程、提取预约收据协议。

## 4. 可运行成果与材料口径

- 可运行成果 = **Android 安装包（debug 构建）**，以已归档的安装包与实机验收记录为准，如实标注 debug 构建与本机验证范围；本轮不新增签名、版本号或分发流水线。
- 赛事材料的截图与运行环境描述以 Android 实机为准；素材替换、匿名化与系统上传仍归正式提交负责人。
- Web 构建产物仍是 Android 壳的界面来源，Web 镜像仍是部署拓扑与离线回放的必需件。「不是客户端」与「仍然必需」同时成立，任何收窄都不得据此删除 Web。

## 5. 代码层收尾延后

删除或下线桌面 Web 工作台、浏览器验收 CI、Web 镜像属于代码层收尾，本 ADR 不执行。这里的冻结指不再新增功能或设计目标，不等于删除或许可遗留缺陷；缺陷修复与安全修补不受影响。

阶段报告、验收记录与旧收据保持原样；口径变更不倒改历史时点。

同时满足以下条件才可启动收尾：

1. Android App 在目标设备上的主流程验收已通过并有记录；
2. 离线回放包不依赖桌面工作台即可独立打开与核对；
3. 部署拓扑已有替代的界面来源，或明确不再提供 Web 镜像；
4. 该改动获得单独的任务授权与验收范围。

在此之前，桌面工作台与 Web 镜像保持冻结、保留，不作为新功能目标。
