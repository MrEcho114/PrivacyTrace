## 4. 音频结论：纯配乐，无人声

**结论：整条音轨是原创器乐（96 BPM），全程无人声。** 官方仅「建议」配音，故**不构成阻塞**，但作为事实记录在此。

| 指标 | 实测 | 含义 |
| --- | --- | --- |
| 整体 RMS / 真峰值 | `-17.51 dBFS` / `-1.59 dBFS` | 响度正常，未削波 |
| 静音占比（<-50 dBFS） | `0.21 %` | 几乎无停顿 |
| 最长静音段 | `0.40 s`；>100 ms 的静音段仅 2 段 | **配音必然会有的换气停顿，这里基本没有** |
| 包络调制峰值 | `3.2 Hz` | = 192 次/分 ≈ **96 BPM 的八分音符网格**，与 BEATS.md 声明的 96 BPM 独立吻合 |
| 频带能量（相对） | 0–100 Hz `-2.7 dB`、100–300 Hz `-6.7 dB`、300–1k `-6.2 dB`、1–3k `-24.0 dB`、3–5k `-41.2 dB`、5–8k `-44.3 dB` | 能量压在 1 kHz 以下、3 kHz 以上骤降；**没有人声应有的 1–3 kHz 共振峰能量** |
| 频谱图 | 全片呈规则竖条（每小节节拍瞬态）+ 低频持续层，无语音的断续爆发结构 | 器乐特征 |

判据：如果存在旁白，1–3 kHz 会有明显共振峰能量、且能量包络会出现 3–5 Hz 的断续音节结构并伴随换气静音。本轨三项都不满足。`README.md` / `BEATS.md` 亦声明「无旁白、无人声」，实测与之独立一致。

> 局限：未安装语音识别依赖，本结论由能量/静音/频带/包络四类客观特征 + 制作文档交叉得出，未做 ASR 文本级否定。
