## 改动

- `apps/web/index.html`：viewport 增加 `viewport-fit=cover`（刘海/底部手势区）与 `interactive-widget=resizes-content`（软键盘出现时缩小布局视口，聚焦控件与其下方操作可滚动到可见区）；保留 `user-scalable`，缩放仍可用。
- `apps/web/src/mobile/viewport.ts`（新增）与 `apps/web/src/main.ts`：在不缩小布局视口、只缩 `visualViewport` 的浏览器里发布 `--keyboard-inset` 与 `html.keyboard-open`。只在 `scale≈1` 时识别键盘（捏合缩放不预留空间）；焦点移到页面底部按钮时不立即释放占位，等视口真正恢复再释放。HMR 时调用返回的 cleanup。不改任何业务流程。
- `apps/web/src/workbench.css`（在 main 的 `theme.css` token 基础上）：
  - 安全区：工作栏、内容区、设置弹层按 `env(safe-area-inset-*)` 留出安全区（底部 inset 只在一层计入）；`workspace-layout` 补 `100dvh` 并扣掉顶部安全区。
  - 软键盘：`html.keyboard-open` 时给页面留出键盘高度、`scroll-padding-bottom` 同步；`.ui-dialog`（A 票 Reka 弹层）最大高度扣除键盘高度与安全区。
  - 触控：44×44 改为能力/宽度分支 `@media (max-width: 560px), (pointer: coarse)`，对 `button`、`.ui-button`、tab、`summary`、文本上传、报告筛选等统一生效；横屏手机与 768px 平板（coarse pointer）不再退回桌面尺寸，并且同时检查宽和高。`pointer: coarse` 下所有文本输入/选择控件（含 `#report-source` 与审阅表单）为 16px/44px；fine pointer 仍保持 14px/40px 契约。
  - 能力分支：`button:hover`、`.ui-button.*:hover` 移入 `@media (hover: hover)`（沿用 `--navy-hover`/`--error` token），触屏不再残留 hover 高亮；桌面指针行为保留。`overscroll-behavior: contain` 也只在窄屏/触屏生效，桌面滚轮链路不变。
  - 大字：`h1/h2/h3` 的固定行高改为 `max(原桌面值, em 比例)`，200% 字号下不重叠且正常宽度仍等于 Pioneer 契约值（40/34、24、22px）；按钮、状态标签、辅助文字、候选摘要等改用比例行高；品牌标记字号设上限。
  - 长文本：`.source-tabs button`、`.ui-field`（单列 `minmax(0,1fr)`）、来源标题 `strong`、报告/对照表单元格等允许断行；报告卡片“当前结论”单元格允许收缩，200% 字号不再局部横滚。
- `apps/web/src/style.css`（同样使用 main 的 token）：hover 规则按能力分支；审阅表单 `minmax(0,1fr)` 网格与输入框 100% 宽度（200% 字号不再撑破 320px）；审阅主按钮允许换行；`pre` 滚动容器 `overscroll-behavior: contain`。
- `apps/web/src/mobile/MobileApp.vue`：内容区安全区内边距；`mobile-field` 单列网格与输入框 100% 宽度（200% 字号修复）。
- `apps/web/src/App.vue`：记录打开证据面板的按钮与当时的 `scrollY`；`closeEvidence()` 关闭后把焦点送回触发行并精确恢复滚动位置；连续打开/关闭两次仍可重复。
- `scripts/verify-mobile-flow.cjs`：在原有端到端 mock 流程上增加 320/768/844×390 视口、长文本、导入/候选/报告 200% 字号、44×44（导入/候选/预览打开/横屏能力分支）、模拟软键盘（占位、失焦保留、捏合缩放、布局视口缩短）、hover/触屏分支、预览焦点与精确滚动恢复、安全区 viewport 断言；设备项写 NOT_RUN。
- `scripts/verify-frontend-flow.cjs`：浏览器工作台的截图与规范检查补 320px；报告页补 200% 字号（320/390）页面溢出、卡片局部横滚、单元格越界、触控宽高和预览焦点/滚动恢复断言。

## 未覆盖（NOT_RUN）

- 真实 Android WebView / 模拟器：软键盘（各输入法实际弹出与 `interactive-widget` 支持）、刘海/手势导航 safe-area 实际内边距、真实触控几何与系统字号、捏合缩放。本次本机没有可用的 `adb`/模拟器（`adb` 不在 PATH，未安装 platform-tools），因此不记真机通过；浏览器模拟与 `visualViewport` 注入只验证 CSS/JS 契约。
- 浏览器“页面缩放”本身未单独验证：本次 200% 指根字号（系统字号/字体放大），页面缩放会把 CSS 视口缩到 195px（390px 的 200%），低于仓库声明的 320px 最小宽度；该情形不记为通过。
- 硬件键盘导航、焦点可见样式与 aria 细节由 D 票负责；桌面层级由 B 票负责；动效由 E 票负责。本次只验证移动软键盘/视口与预览关闭返回焦点。
- 320px + 200% 下候选卡仍是 88px 标签列 + 原句两列，可读但偏紧；无横溢/遮挡，未改这一既有窄屏排版（可后续由 B/D 视觉层级处理）。
- 合并、部署、发布不在本记录授权内。
