### 为什么做
S1 已有隔离解析、政策摄取、持久化和页面链路，但权限边界、版本号编码、重复任务并发及示例来源冲突仍会造成漏报、错误失败或报告串用。先消除这四项缺陷，再进入受控场景和基准评测。

### 完成标准（验收证据）
- 自建二进制 AXML/DEX 回归覆盖两种权限标签、SDK 上限、整数编码和非法版本号。

- 真实 `demo` 作业与人工示例可分别查看；备注和取消指向原始 Job ID。
- 后端、lint、契约导出、前端测试和构建通过；本机未执行的 Docker 项与远程 CI 分开记录。
