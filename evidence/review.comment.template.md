# S1 双人人工复核 comment 模板

正式入口：[Issue #15](https://github.com/MrEcho114/PrivacyTrace/issues/15)。A、B 两位技术成员各用自己的 GitHub 账号发布一条 comment，不再填写签字栏。使用下方模板；位置与原文在本地私有材料中核对，公开 comment 只写证据 ID、哈希、区间和核对理由，不上传 APK、完整政策或反编译全文。

以 comment URL、作者账号及 GitHub 时间戳留痕。工具代发、Codex 测试备注、单条“同意”或代理填写的名字均不是两位成员的人工复核。需要确认账号对应 A、B；两条 comment 不能由同一人代写。

```markdown
## S1 人工复核 — [A 或 B]
- GitHub 账号：@[自己的账号]
- 复核对象：PR #27；实现提交：[完整 SHA]
- 样本版本及 APK SHA256：[填写]
- 政策版本、采集时间及 SHA256：[填写]
- 规则版本：[填写]

| 证据/声明 ID | 核对内容（调用位置或原文 span、主体/否定/条件） | 结论与理由 | 未覆盖项/争议 |
| :--- | :--- | :--- | :--- |
| [逐条填写，不能只填总体同意] | [填写] | [填写] | [填写] |

- 全文与适用性：广泛否定声明、未提取范围、地区、附件、版本关联的核对结果及仍缺证据：[填写]
- 总体结论：[通过 / 需修改]；仅为本阶段技术证据核验，不作合法性、安全性或实际采集判定。
- 分歧及处理：[无 / 具体问题和处理；仍待解决不能直接通过]
```
