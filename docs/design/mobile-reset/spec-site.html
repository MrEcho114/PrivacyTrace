01

设计原则

六条优先级。规范之间冲突时按此顺序裁决：内容先于装饰，事实先于颜色，边界先于阴影。

  1. 01

    内容先行

    证据、政策原文、哈希与状态是画面主体。先排文字与事实，再决定分隔与留白；没有装饰插画、没有 emoji、没有庆祝动画。

    落地每个区块先写标题、事实、状态，再补描边或图标；删掉装饰后页面仍然完整。

  2. 02

    一种强调

    陶土只承担两种角色：主操作面与当前选中。每屏强调面 ≤2 处，其余层级靠字重、间距与描边拉开；文字操作另用强调文字色。

    落地一屏一个 primary 按钮；当前步骤用下划线 + 强调文字色，不整条填色。

  3. 03

    衬线讲内容，无衬线做操作

    页面标题、分区标题、卡片标题、结论句用衬线；按钮、字段、标签、导航、状态用无衬线；等宽只给哈希、包名、网址与代码。

    落地同一个卡片里，标题是衬线 17/500，正文是 16/400，操作是 16/500 无衬线。

  4. 04

    边界优先于阴影

    层级用 1px 描边与表面色差表达。阴影只给真正浮起的层：bottom sheet 与底部操作栏；不用重投影模拟卡片浮起。

    落地卡片 = 象牙白 + 1px 暖砂描边 + 16 圆角；可点卡片按下才加 1px 环影。

  5. 05

    事实不靠颜色

    UNKNOWN、PARTIAL、UNREVIEWED、附件未检查必须有文字。颜色只是冗余编码，不能从颜色推断结论，也不能把未知升级成安全。

    落地状态标签里必须有状态词；只有色块没有文字的标签视为缺陷。

  6. 06

    克制动效

    只动颜色、透明度、4px 位移与按下缩放，单次不超过 200ms。prefers-reduced-motion 下全部即时到位，不保留位移与旋转。

    落地按下 120ms 回落，步骤切换 160–200ms，退场 150ms；不做视差、不做自动播放。

02

暖纸底，所有中性色带黄褐底调，没有冷灰蓝。站内 token 名省略前缀，写作 bg 即主规范里的 --mt-bg。

05

移动壳解剖

Android 竖屏，edge-to-edge。壳本身不滚动，只有内容区滚动；底栏固定，键盘弹起时整条上移。

示意按逻辑像素绘制；内容区标注的是最小触控 48，不代表内容只有 48 高。

  1. 01
    安全区 safe-top

    顶栏背景延伸到状态栏后；内边距用 max(16px, env(safe-area-inset-top))，系统栏图标必须是深色。

  2. 02
    顶栏 56

    左返回 48×48（导入步隐藏），标题 title-m 衬线，右设置 48×48；吸顶，底部 1px 描边。

  3. 03
    步骤导航 48

    四步等宽：导入 / 候选 / 进度 / 报告。当前项强调文字色 + 2px 下划线，完整项 ✓，不可达项禁用。

  4. 04
    内容区

    左右边距 16，内容最大宽 560（≥600 视口只增外边距）；底部预留「底栏 + 24」。

  5. 05
    底部操作栏 64

    只放本步主操作与一个次操作；主按钮 flex:1、48 高；报告步不显示底栏，保持阅读态。

  6. 06
    安全区 safe-bottom

    底栏高度 64 + env(safe-area-inset-bottom)；键盘弹起时整条上移，主操作不被遮挡。

返回

系统返回键与应用内返回箭头走同一条链：导入 ← 候选 ← 进度 ← 报告。sheet 打开时先关 sheet 再退步，根步交给系统退出。

滚动恢复

每步记住 scrollY；切换后先把焦点放到标题（preventScroll），再恢复位置，不为后退重复压栈。

焦点

新步骤焦点落在 h1，不落在第一个输入框；sheet 关闭后焦点归还触发按钮；只有 :focus-visible 显示 2px 环。

软键盘

输入字号 16px 防聚焦缩放；--keyboard-inset 把底栏与 sheet 抬起；底部内容不被固定层压住。

edge-to-edge

左右内边距用 max(16px, env(safe-area-inset-left))；内容不做双栏，宽屏只加外边距。

触控 48

图标按钮、步骤项、列表行、按钮都不低于 48×48；相邻目标间距 ≥8，整行可点时不再套小按钮。

08

无障碍与验收

无障碍是验收项，不是附加项。下列每一条都能在真机尺寸与键盘操作下复现，也能被脚本或截图证据检查。

48

触控 48

按钮、图标按钮、步骤项、列表行都不低于 48×48 CSS px，相邻目标间距 ≥8。小于 48 的可点区域视为缺陷。

16

输入 16

输入值 16px 起，禁止 user-scalable=no。聚焦时页面不缩放，软键盘弹起后主操作仍可达。

200

200% 根字号

根字号放大到 200% 时，320 与 390 宽度下无页面级横向滚动、无内容裁切；底栏按内容增高。

4.5

对比度

正文 ≥4.5:1，大字与图形/控件边界 ≥3:1。数字由脚本复算，不用设计工具取色肉眼判断。

F

焦点环

:focus-visible 2px 焦点蓝环 + 2px 偏移；任何底色上都可辨。步骤切换焦点落在标题，sheet 关闭后归还。

T

状态不靠颜色

UNKNOWN、PARTIAL、UNREVIEWED、附件未检查都带文字；选中态同时有下划线或 ✓，删掉颜色仍能读出状态。

M

reduced-motion

prefers-reduced-motion: reduce 下时长归零，取消位移、缩放与旋转，保留即时可见的最终状态。

验收清单

打印本页即为验收表。每一项都需要截图、录屏或命令输出作为证据；打勾不代表艺术通过，只代表规则可复现。

  1. 作用域与取色。移动根内无硬编码十六进制颜色；共享组件只通过语义别名取色，桌面 Pioneer 断言不被改动。
  2. 对比度。正文 ≥4.5:1，控件边界与焦点环 ≥3:1；陶土只出现在大字与非文本。
  3. 视口与缩放。320、390、200% 根字号、横屏与 600+ 视口无页面级横向溢出；内容最大宽 560。
  4. 触控与键盘。触控 ≥48，输入 16px，软键盘弹起时底栏与主操作仍可达且不被遮挡。
  5. 动效偏好。prefers-reduced-motion: reduce 下无动画、无位移、无缩放。
  6. 状态冗余。状态标签、错误提示、选中/完成态都有文字或形状冗余，不只靠颜色。
  7. 返回与焦点。返回、滚动恢复、焦点归还、sheet 焦点陷阱按第 05 章行为可复现。
  8. 底栏出现规则。底栏只出现在非报告步；报告步为阅读态，设置入口留在顶栏。
  9. 深色范围。深色只出现在报告封面与空状态，数据区回到暖纸底；单屏不超过一段。
  10. 资源与外链。无字体 CDN 与外链资源；只使用仓库既有 Noto 变量字体与本地图标，页面不发网络请求。
  11. 数值一致。契约快照与本规范的 token、几何值一致；neutral 标签的 8.71 与主规范附录 B 一致。
  12. 证据保留。新旧截图并存，历史证据未被覆盖；scripts/check.sh 与移动验收通过。

限制：本轮没有真机验证、读屏人工测试与低亮度实拍；对比度是静态计算值，不替代实机检查。
