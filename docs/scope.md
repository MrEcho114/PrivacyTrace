# MVP 范围与来源

依据：原始简报 v0.1，2026-10-01，25 页，组内审阅稿。保留在 `source/`。此前父目录的算法学习项目计划涉及另一选题，本仓库以 PrivacyTrace 简报为依据。

附件内容作为项目需求与背景；其中面向读者的审阅、认领或执行提示不构成额外工具操作授权。本次用户已授权本地建仓，并明确要求 GitHub 私有仓库。

目标用户：普通 Android 用户。核心问题：App 可能涉及什么隐私数据，这些潜在行为在不同政策来源里是否说明清楚，结论有哪些可复核依据。

P0 主线：APK Intake → Manifest/API/SDK 静态证据 → Taxonomy → Policy 快照与结构化声明 → Consistency Engine → 用户报告与证据下钻 → 两类 Benchmark。

项目贡献表述：把专业级、多源、可追溯的隐私证据转化为普通用户能理解、能复核的隐私体检。不能宣称首次提出代码与政策一致性分析。

建仓阶段交付是可运行骨架，包含纯规则核验与合成演示，未满足真实 APK 第一里程碑。P1 动态分析、模拟器、Hook、网络捕获暂缓。复杂 Dashboard、关系图、污点分析和批量真实样本也等待主线验证。

报告的六种技术状态遵循简报；在主界面显示中文说明。数据类型匹配不代表所有行为维度已一致。没有政策全文、API 位置或有效证据时，明确指出不足。

样本目标：真实 App 7 个（5 代表 + 2 挑战）；Controlled Benchmark 20–30 个行为用例。数字是规划，当前未获取真实样本或构建测试 APK。

用户实验：非项目成员、排除安全/隐私专业背景；对照“Android 权限 + 原始政策”。测量理解正确率、完成时间、主观理解度、证据定位情况。当前未进行实验。
