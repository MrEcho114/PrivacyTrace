- 真实 Android 真机/模拟器/WebView、Tauri APK 构建与签名；本机无 adb/emulator/Android SDK。
- 真实系统状态栏/刘海/手势安全区、真实软键盘 IME、系统字体缩放/捏合、TalkBack。
- 真实 NVDA/VoiceOver/Orca 人工读屏；Chromium AX tree 不等于读屏体验。
- 真实 APK 扫描、Docker、模型、外部政策网页；浏览器夹具为确定性模拟。
- sheet 退出 150ms 未实现（当前即时卸载）；步骤切换/动效只在 Chromium 模拟与 6× CPU 节流下验证。
- 合并、部署、发布、正式提交不在本轮授权内；本汇总不替代 #128 的完整业务验收。
