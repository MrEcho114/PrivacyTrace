# Issue #146 · 第二轮：Android 外壳的动效与减少动态效果

来源任务：[#146](https://github.com/MrEcho114/PrivacyTrace/issues/146)，父票 [#141](https://github.com/MrEcho114/PrivacyTrace/issues/141)。
第一轮交付：[PR #156](https://github.com/MrEcho114/PrivacyTrace/pull/156)，head `c1a11f8`（hover 门控、颜色反馈、减少动态效果、证据展开无动画）。
第二轮把动效接到 #144 的 Android 竖屏外壳与 A 的 `UiSheet` 上，默认动效只解释状态，不遮住证据。设计合同见 `docs/design/frontend-round2-android-pioneer.md` §6。

## 本轮实际改动

- `theme.css` 新增 `--m-duration-press: 120ms`、`--m-duration-enter: 200ms`、`--m-duration-exit: 150ms`、`--m-ease-standard`、`--m-ease-decelerate`；外壳/组件只消费这些值，不再散落硬编码时长。
- `UiSheet`（Reka Dialog）进入：scrim 淡入 + bottom sheet `translateY(24px)→0` + opacity，200ms；`detail` 全屏只淡入；`animation-iteration-count: 1`，不做 idling 循环。关闭时父组件卸载，exit 为即时（不做高度/宽度动画，避免布局跳动）；如实记录为「entry only」，不宣称 150ms 退出已实现。
- 步骤切换：`main.m-step-enter` 160ms opacity + 4px 位移，首帧内容即可读；`animationend` 后移除类，不残留 transform。
- 移动按钮/候选行/chevron 使用 120–150ms 的颜色/位移过渡；只过渡 `background-color`、`border-color`、`transform`、`opacity`，没有 `transition: all`。
- `prefers-reduced-motion: reduce`：`mobile.css` 与 `workbench.css` 都让 transition/animation 接近即时，`scroll-behavior: auto`；`App.vue` 的证据滚动 `behavior` 在 JS 层选择 `auto`；sheet 进入动画 `none`，步骤动画 `none`。
- 数据轮询/原地刷新不因动画重挂载、不抢焦点、不延迟操作；长文本、后台恢复、6× CPU 节流下证据首帧可读。
