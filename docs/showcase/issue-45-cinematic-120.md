# Issue #45：两分钟镜头与文字稿

用户于 2026-10-15 要求学习 Pioneer 的实际镜头、加入创造性设计，并把片长控制在两分钟。本稿取代上一轮 180 秒／20 镜的时长与编排约束；[上一轮文案](issue-45-copy-rewrite.md)和[Gemini4 原稿](gemini4-director-review.md)仅作历史来源。当前分镜以 `showcase/privacytrace/storyboard.json` 为准。

用户随后要求片头直接陈述本应用功能，去掉提问、API 式措辞和含糊比喻。副标题改为“核对应用权限与隐私政策”；说明改为“集中查看权限、政策说明和分析结果，随时查阅对应依据。”

## 镜头意图

参考实际观看的 Pioneer Cinematic v8 60 秒成片及其分镜源文件，采用三种有依据的方法：有厚度的斜置界面、短暂景深后回到清晰正面、同一任务连续推进。参考片在 8–19.8 秒建立空间层次，在 31–54 秒保持工作台连续，结尾回到开场母题。PrivacyTrace 自行设计形状与文字，没有采用 Pioneer 的 CRT、角色、素材或配乐。

开场让测试安装包、静态调用与政策原句逐层展开；9 秒切入三张实录界面的空间长廊。16–74 秒保持同一任务，把运动压在每镜开头与结尾，关键原句和代码正面停稳。74–83 秒将代码和政策作为两页证据摊开，连接到真实报告中的“证据不足”；这个连接只组织可回查依据，不表示运行时数据流。113 秒后回到开场的层叠形状，材料收拢到报告。

`cinema.js` 使用解析透视投影和局部纹理网格；本地经典脚本支持直接离线打开。每镜的进入、静止阅读与退出时段均在分镜中明确，跳转不依赖上一帧。读取产品内容时使用正面、无滤镜的原始截图。案例比较各保留两张原文与结果，避免四张密集卡片同屏。
